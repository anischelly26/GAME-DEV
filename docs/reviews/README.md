# Reviews

This folder belongs to the independent reviewer (Codex). Claude does not edit review findings.

- Design inputs from the creative owner and Codex: `CLAUDE_DESIGN_PROMPTS.md`,
  `CLAUDE_FUN_AND_PARKOUR_PROMPTS.md`.
- Suggested name for review reports: `REVIEW-<yyyy-mm-dd>-<short-sha>.md`, one per tested commit.
- Claude's responses to a review go in the pull request or in `docs/STATUS.md`, citing the
  finding and the fixing commit.
