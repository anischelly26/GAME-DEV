# Assets, sources and licences

## Game content

All visual and audio content in this build is generated by code in this repository. There are no
external images, models, fonts or sound files.

| Content | Source | Status |
| --- | --- | --- |
| Stone, floor, iron, brass, wood, wool and fabric textures | Procedural (`src/world/textures.ts`), fixed seeds | Placeholder-quality, original |
| Diagram, gauge face, valve plate, stencilled signs, salt stains | Procedural canvas drawing (`src/world/textures.ts`) | Original |
| Architecture, props, mechanisms | Procedural geometry in code (`src/levels`, `src/world/props`) | Proxy art, original |
| Mara (character model and animation) | Primitive shapes with procedural animation (`src/player/PlayerAvatar.ts`) | **Proxy model**, not final character art |
| Sky, water, light shafts, dust, steam | Shaders and particles in code (`src/world/Atmosphere.ts`) | Original |
| Sound effects and ambience | Synthesised at runtime with Web Audio (`src/audio/Audio.ts`) | **Placeholder** sounds |
| UI fonts | The player's system fonts (Palatino/Georgia, Segoe UI/system-ui); nothing is bundled | — |
