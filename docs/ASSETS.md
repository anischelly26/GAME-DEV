# Assets, sources and licences

The game uses four kinds of content:

- third-party **CC0** (public-domain) assets: Mara's model and animations, the photographed
  surface textures, sound and music;
- two third-party **CC BY 4.0** models (Chapter Two): a playground slide and a lighthouse scan.
  CC BY needs credit and an indication of changes; both are given below, in each file's glTF
  `asset.extras`, and on the title screen;
- content **generated by code** in this repository;
- open-source libraries.

There is no paid content. Sound and music are CC0 recordings (below), with Web Audio synthesis for
steam and machinery.

### How `mara.glb` is built

`npm run import:mara` (= `node scripts/import-mara.mjs`) rebuilds `public/assets/mara/mara.glb`
from the packs above. The packs themselves are not committed. Download them from the links,
unzip into `import-cache/quaternius/` (git-ignored) keeping the pack folder layout, and add
`UAL1_Standard.glb` (the Godot GLB from the first animation library) and `UAL2_Standard.glb`.
Then run `npm run dev` and the import script.

The assembly runs in the browser (`tools/maraAssemble.ts`):

1. **Head.** The base body is cut to the head and neck. The outfit pack's readme says only the
   head is needed; the full body would show through the clothes.
2. **Outfit.** The ranger outfit, minus hood and pauldrons, with its greens hue-shifted to ochre.
3. **Hair.** Buns, tinted auburn.
4. **Skeleton.** Everything is bound to one skeleton.
5. **Clips.** Each animation clip is retargeted with world-space rotation deltas
   (`tools/retarget.ts`), because the first library uses Blender/Rigify bone names and different
   bone axes. Horizontal hip travel is removed, because the game's controller moves Mara;
   vertical motion (lying down, getting up, climbing) is kept.
6. **Export.** Textures are re-encoded as 1024 px JPEG and exported as one binary glTF: about
   8.0 MB, 32k triangles, 29 clips (the clip table is `CLIPS` in `tools/maraAssemble.ts`; the
   game-feel pass added `swimIdle`, `swimFwd`, `drive`, `hitHead` and `talk`, 7.44 → 7.98 MB).

`node scripts/capture-character.mjs` renders turntable views from the dev viewer
(`/?viewer=mara`).

### Surface textures

`node scripts/fetch-textures.mjs` downloads the Poly Haven sets at 1k (diffuse, OpenGL normal,
and packed AO/roughness/metalness) into `public/assets/textures/`. It also writes `manifest.json`
with each texture's real-world size; the game tiles every set at that size. About 25 MB in all;
each chapter loads only the sets it uses (`surfaces` in `src/levels/chapters.ts`).

**Not used.** The Sketchfab models the owner suggested earlier (prison rooms, an aircraft in a

authorisation from their owner; this project does not use them.
